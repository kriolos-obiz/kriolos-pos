Documentation for KriolOS POS is structured as an **Antora** component.

== Structure

* `antora.yml`: Component descriptor.
* `antora-playbook.yml`: Antora site playbook.
* `modules/`:
** `ROOT/`: Main landing page (`pages/index.adoc`) and global navigation (`nav.adoc`).
** `guide-devel/`: Developer guide pages and architecture docs.
** `guide-user/`: User manual and setup instructions.
** `guide-comercial/`: Commercial product vision and licensing.
** `guide-migration/`: Migration roadmap and deep analysis.
** `notes/`: Technical research and architecture notes (e.g. taxes, rounding).

== Building the Documentation

=== Using Antora (Default)

The documentation build runs with Antora by default:

[source,bash]
----
mvn generate-resources -f docs/pom.xml
# Or from the project root:
mvn --projects docs generate-resources
----

Generated site output will be located in: `docs/target/antora/site/`.

=== Using AsciiDoctor (Legacy Profile)

To build using the legacy AsciiDoctor plugin:

[source,bash]
----
mvn generate-resources -f docs/pom.xml -P asciidoctor
----

NOTE: Each module under `modules/` contains a master `.adoc` file (`guide-devel/guide-devel.adoc`, `guide-user/guide-user.adoc`, `guide-comercial/guide-comercial.adoc`, `guide-migration/guide-migration.adoc`, `notes/notes.adoc`) used by the `asciidoctor` profile to compile one comprehensive PDF per module into `docs/target/generated-docs/pdf/`.
