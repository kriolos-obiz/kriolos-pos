= Legacy Architecture Overview
:description: Architectural documentation, domain boundaries, and code smell analysis of the inherited legacy Openbravo / uniCenta POS foundation.

Welcome to the **Legacy Architecture** module of KriolOS POS.

This module documents the architectural state, technical debt, and monolith structure inherited from Openbravo POS and uniCenta oPOS. It serves as the baseline record to guide the long-term extraction of clean, decoupled business modules.
