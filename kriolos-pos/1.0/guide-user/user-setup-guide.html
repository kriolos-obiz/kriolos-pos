Setup & Installation

This chapter describes how to launch and initialize KriolOS POS for first-time use based on the distribution artifacts generated by the project build.

System Prerequisites

  • Java Runtime: OpenJDK 17 or higher (Eclipse Temurin recommended) when running from JAR.

  • Display: Minimum screen resolution of 1024x768 (touch-screen optimized).

  • Database: Embedded Apache Derby, MariaDB 10.5+, MySQL 8.0+, or PostgreSQL 12+.

Launching the Application

KriolOS POS provides two distribution formats:

1. Native Distribution (jpackage)

Built via the kriolos-krpos-jpackage module:

  • Standalone Image Directory (kriolosPOS-image-*):

    • Linux: Run ./bin/kriolosPOS (or ./bin/kriolosPOS-Config for configuration)

    • Windows: Run kriolosPOS.exe (or kriolosPOS-Config.exe for configuration)

    • macOS: Open kriolosPOS.app

  • Native System Installers:

    • Install via system package manager (.deb on Debian/Ubuntu, .rpm on Fedora/RHEL, .msi on Windows, .dmg on macOS).

    • Launch using the created application desktop/menu shortcut.

2. Standalone Java Archive (kriolos-opos-app-*.zip)

Built via Maven assembly with the runtime lib/ directory:

  • Main POS Application:

    java -jar kriolos-opos-app-1.0.0-SNAPSHOT.jar

  • Configuration Panel:

    java -cp "kriolos-opos-app-1.0.0-SNAPSHOT.jar:lib/*" com.openbravo.pos.config.JFrmConfig

Default Users and Roles

Upon initial startup with a standard dataset, the following default credentials are provisioned:

Username Password Role Description

admin

admin

ADMIN

Full administrative access, back-office configuration, user management.

manager

manager

MANAGER

Store manager, end-of-day reports, cashier supervision.

empl

empl

EMPLOYEE

Standard cashier, sales registration, and receipt generation.

For production environments, it is recommended to update default credentials via the Administration → Users panel.
